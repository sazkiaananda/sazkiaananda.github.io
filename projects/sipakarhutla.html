SIPAKARHUTLA.

Android app for recording and reviewing forest and land fire assessments after a fire.

ROLE · ANDROID DEVELOPERPERIOD · JAN—AUG 2026FOCUS · MOBILE + SUPPORTING API WORK

PROJECTUndergraduate thesis and faculty project

PLATFORMAndroid

TECHNOLOGYKotlin · Android SDK · Room · SharedPreferences

LIBRARIESGoogle Maps SDK · TensorFlow Lite

APIREST endpoints for offline sync and map/report workflows

What the app supports

Field staff record site conditions and plot-level observations. The app helps capture location, represent assessed land on a map, manage reports, and review severity information.

What I worked on

  • Continued an existing Kotlin Android app, with mobile development as my main focus.
  • Added GPS-based location capture for offline entries and a draft flow that fills in administrative-area details after upload.
  • Added auto-save and draft recovery for unfinished observation forms.
  • Built polygon mapping and spatial checks, and enabled adding plots while editing an existing report.
  • Added a report map and integrated on-device photo classification using TensorFlow Lite.
  • Supported API changes for offline sync, report updates, and map data.

Field use

The application was demonstrated and tested with Manggala Agni field staff, who tried the app features and shared usability feedback.
