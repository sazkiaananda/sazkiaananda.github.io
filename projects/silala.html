SILALA.

Flutter prototype for BPMSPH’s digital library and archive service, designed to make books and technical references easier to find.

ROLE · MOBILE APPLICATION DEVELOPER INTERNPERIOD · SEP—DEC 2025FOCUS · FLUTTER UI + APP FLOWS

ORGANIZATIONBPMSPH · Bogor

ROLEMobile application intern

PERIOD22 Sep—30 Dec 2025

TECHNOLOGYFlutter · Dart

DELIVERABLEMobile prototype · pre-integration

The need

Staff had to search the physical library and archive room for work guidelines, procedures, regulations, and other technical references. SiLALA was planned to make collection details and digital reading materials easier to access, and to support book availability and borrowing workflows.

My work

  • Designed and built the main mobile screens in Flutter, following the existing website design and adapting it for phone use.
  • Implemented navigation and basic validation across login, registration, home, catalogue, and book-detail screens.
  • Built interface flows for search, category browsing, borrowing confirmation, favorites, reading/borrowing history, and PDF viewing.
  • Refined layouts and interactions iteratively, using sample data while developing the prototype.

Project scope

The internship deliverable focused on the mobile prototype and core app flows, developed and reviewed using sample data.
