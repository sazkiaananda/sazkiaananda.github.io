# Sazkia Ananda Zykry — portfolio

A static, responsive mobile-development portfolio with a dark, high-contrast visual style, CSS phone mockups, project case studies, and downloadable credentials. It uses plain HTML/CSS and has no build step or external dependencies.

## Pages and assets

- **index.html** — introduction, projects, experience, education, campus activities, and contact.
- **cv.html** — readable CV preview followed by PDF and editable Word downloads.
- **projects/sipakarhutla.html** — Android project summary, app screenshots, and field-testing certificate link.
- **projects/silala.html** — internship project summary and three app screenshots.
- **credentials.html** — downloadable course certificates, English test copy, and project-participation certificate.
- **assets/cv/** — one-page CV in PDF and editable Word formats, linked from the CV preview page.
- **style.css** — shared responsive styling.
- **assets/projects/** — app screenshots shown inside phone mockups. The SILALA home image has account details anonymized.
- **assets/certificates/** — course and participation certificate PDFs. The English test PDF is a redacted public copy.

The project descriptions summarize your work without publishing the full thesis or internship report. The case studies focus on the problem, your contribution, and the app screens; they leave out detailed error and test-score reporting.

## Publish with GitHub Pages

1. Create a GitHub repository. A public repository named YOUR-USERNAME.github.io creates a user site at https://YOUR-USERNAME.github.io/.
2. Upload the contents of this folder to the repository root. Keep the **assets** and **projects** folders.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**.
5. Save and wait for GitHub Pages to finish publishing.

Official setup guides:

- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

- Review each project description and screenshot for details you are comfortable sharing publicly.
- The SILALA home screenshot has identifying account text anonymized. The English test copy has date of birth, test ID, and QR code removed.
- No BPMSPH internship-completion certificate is included because none was provided. The internship is presented through the project summary and app screenshots. If an employer asks for formal proof, request a PKL completion letter from your BPMSPH supervisor or office.

The page has no analytics or contact form. The email link opens the visitor's email application.
